# vidashort

A ReelShort / HiDrama-style microdrama app for the Nigerian market.

## Status

**Phase 0.5 — visual prototype complete.** 43 clickable HTML screens, all flows wired, full data layer, in `apps/design/`.

Next: Phase 1 (Expo mobile skeleton), Phase 2 (FastAPI backend). See `docs/phases/00-roadmap.md`.

## Quick start (prototype)

```bash
# Just open the file. No build.
start apps/design/index.html
```

Or right-click `apps/design/index.html` → "Open with" → browser.

## Repo layout
